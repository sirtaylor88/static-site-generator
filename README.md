# static-site-generator

## Install dependencies

```bash
pyenv local 3.12.9
source .venv/bin/activate
pip install poetry
poetry install
```

## Build and run

```bash
./main.sh
```

## Run test

```bash
./test.sh
```

## Build pages

```bash
./build.sh
```

The generated page can be accessed at [Tolkien Fan Club](https://sirtaylor88.github.io/static-site-generator/)
